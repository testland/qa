# qa-mobile-native

Mobile + mobile-web E2E testing — closes the platform gap left by web-focused E2E plugins. Native frameworks (XCUITest, Espresso), cross-platform drivers (Appium, Detox, Maestro), Flutter widget/integration tests, plus a device-matrix dispatcher, mobile-web emulation runner, touch-gesture tester, and mobile Web Vitals budget.
