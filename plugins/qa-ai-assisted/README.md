# qa-ai-assisted

AI-assisted test generation + curation. AI-generated tests from natural-language specs, coverage gap mapping, an adversarial reviewer for AI-generated tests (catches hallucinations, weak assertions, redundancy), plus a model-based-test graph authoring skill that produces the input AI test generators benefit from.
