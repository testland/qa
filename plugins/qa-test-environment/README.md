# qa-test-environment

Test environment management: containerized backing services (Testcontainers + docker-compose), per-test database snapshot/restore, feature-flag combinatorial test harness, and reusable Playwright fixtures. Plus a cross-plugin reference to the parallel-isolation checker that lives in `qa-flake-triage`.
