# qa-localization

Localization (l10n) and internationalization (i18n) testing — closes the entirely-missing localization category in the existing ecosystem. String-coverage detection of untranslated strings, pseudo-localization for surface-level layout testing, RTL rendering verification, locale-specific format validation (dates, numbers, currencies).
